# Introduction

The project was created to analyze the differences in the microbiomes of two groups. 

# Run

All the necessary data are included in the "./data" folder. The calculated statistics will appear in the "./result" folder, which will be created automatically after running the Run.R script. 

# Publication

This code was used to generate statistical analysis for the publication Gut microbiota-metabolite alterations associated with early metabolic dysfunction and hepatic steatosis in adolescents and attached to zenodo [![DOI](https://zenodo.org/badge/1166540603.svg)](https://doi.org/10.5281/zenodo.20410274)
